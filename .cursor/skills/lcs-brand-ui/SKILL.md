# LCS brand UI

## Tokens

Use CSS variables: `--lcs-black`, `--lcs-charcoal`, `--lcs-gold`, `--lcs-gold-soft`, `--lcs-white`, `--lcs-muted`.

## Layout rules

- First viewport: brand, one headline, one supporting line, CTA group, full-bleed hero media.
- No cards in hero; no purple/cream AI-default themes.
- Display font geometric/industrial; body sans readable.
- Motions: hero entrance, section reveal, project hover — max intentional set.
- P&M is IA reference only; visual identity must read as LCS with logo present.

## Content

Spanish copy. Prefer portafolio facts (misión, cobertura, obras públicas).
